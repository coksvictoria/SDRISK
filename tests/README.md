# Tests

M1 tests cover schema and bundle validation, policy loading, provenance, applicability,
metric-result constraints, and disclosure-safe aggregate filtering. M2 adds
hand-computable mixed-type encoder and distance tests, nearest-neighbor checks against
brute force, blocking behavior, and reproducible subsampling. Later milestones will add
attribute and membership metric tests, broader planted-leak fixtures, export scans, and
broader performance tests. M3 adds hand-computable table-level identity metrics and
generated monotonic copy-leak tests.
